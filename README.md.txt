# 📊 Sales Performance Dashboard (Power BI)

##  Overview
This project presents a sales dashboard built using Power BI to analyze business performance across regions, products, and customers.

It focuses on turning raw data into actionable insights for decision-making.

---

##  Objectives
- Analyze total sales and profit
- Identify top-performing regions and products
- Understand customer behavior
- Compare sales channels and payment methods

---

##  Tools & Technologies
- Power BI (Data Visualization)
- Python (Data Cleaning)
- Pandas (Data Analysis)

---

##  Dataset Description
The dataset contains 1000 sales records with:
- Product information
- Sales transactions
- Customer types
- Payment methods
- Regional performance

---

##  Key Metrics
- **Total Sales:** 5.02M  
- **Total Profit:** 6.49M  
- **Quantity Sold:** 25K  

---

##  Key Insights
- North region generates the highest revenue and profit
- Clothing is the top-selling category
- Retail sales are slightly higher than online
- Credit Card is the most used payment method
- Discount behavior is similar across customer types

---

##  Dashboard Features
- Interactive filters (Region, Category, Channel)
- Sales and profit comparison
- Time analysis (Month & Year)
- Clean and user-friendly design

---

##  Automation
The dashboard is connected to a CSV file.  
Updating the dataset and refreshing Power BI automatically updates all visuals.
